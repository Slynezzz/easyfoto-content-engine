## 1. Цель продукта
Коробочный движок экспертного контента для персонального использования: эксперт любой ниши
покупает завод «с установкой и запуском» и получает бота в Telegram, который:
- каждый день ищет тренды, новости и проблемы его ниши и предлагает темы;
- по выбранной теме делает пост с картинкой, карусель, «переписку с ботом» или ролик с музыкой —
  с фактами из интернета и источниками, текстом под правила каждой соцсети;
- присылает готовое на одобрение; по умолчанию владелец публикует вручную.

**Модель продажи (как задумал владелец):** покупатель регистрирует своего бота в @BotFather →
Максим копирует репозиторий и разворачивает сервер (Railway или Amvera) → вписываются минимум
переменных (ключ посредника, токен бота; остальное — заглушки) → движок работает.
Тонкая настройка YouTube/Instagram/автопубликации — отдельная платная услуга или сам покупатель.

**Главное требование:** развернул и работаешь — минимум настроек и шагов.

## 4. Целевой опыт покупателя (цель — 5 простых шагов)
1. Создать бота в @BotFather, скопировать токен.
2. Нажать «Deploy» (шаблон Railway) или создать проект в Amvera по инструкции.
3. Вписать 2–3 переменные: токен бота, ключ посредника, ключ лицензии.
4. Написать боту `/start <ключ лицензии>` — стать владельцем.
5. Пройти мастер настройки (8–10 вопросов) → получить первые темы и первый пост.

## 5. Архитектура коробки (предложено, ждёт решений)
1. **Чистый шаблон без данных Максима.** Вынести из кода в его личный профиль:
   `engine/prompts/brief_expert.md`, `engine/niches/expert.json`, `engine/niches/neurophoto.json`,
   `engine/assets/Karpov_checklist_12_zadach.pdf`, тексты «AI-Photo» и Easyfotobot в `engine/server.py`,
   упоминания @slyness_bot, @max_karpov, «AI-архитектор» в коде и стратегии, `docs/` (GitHub Pages).
2. **Профиль в базе, а не в коде.** Бриф, запросы разведчика, сегменты, возражения, тон, сцены,
   тексты бота заявок — в БД покупателя; одна версия кода для всех. Правка — `/profile`.
3. **Мастер настройки при первом запуске.** Вопросы (можно голосовыми): кто вы и город; услуги;
   клиент и его боли; реальные кейсы и цифры; запретные темы; площадки; 3–5 экспертов/конкурентов
   для ориентира. Нейросеть собирает профиль → владелец подтверждает → первая разведка → темы кнопками.
4. **Один ключ посредника** на тексты, картинки и поиск (например, OpenRouter: модели с суффиксом
   `:online` ищут в интернете и дают ссылки; генерация картинок с фото-образцами). Tavily/Perplexity — опция.
5. **Владелец по ключу лицензии** вместо `ADMIN_CHAT_ID`: `/start <ключ>` закрепляет владельца.
6. **`/doctor`** — самодиагностика: ключ, баланс, бот, канал, поиск, диск — с понятными подсказками.
7. **По умолчанию — ручная публикация** (готовый пост + текст), Telegram-канал — если бот админ канала.
   Instagram/YouTube/VK — платная донастройка.
8. **Лимиты расходов:** суточный лимит картинок есть; добавить месячный лимит денег с предупреждением.
9. **Лицензия:** проверка ключа на сервере лицензий Максима (есть у AccessBot) + договор-оферта;
   обновления — по действующей лицензии.
10. **Развёртывание:** шаблон Railway (сервис + том `/data` + 3 поля); `amvera.yml` + инструкция.
    `PUBLIC_BASE_URL` брать из `RAILWAY_PUBLIC_DOMAIN` автоматически.

### Хостинг
- **Amvera:** оплата в рублях, встроенное проксирование к API OpenAI/Gemini/Claude. Не подтверждено,
  что оттуда работают API Instagram и YouTube → подходит для режима «генерация + ручная публикация».
- **Railway:** нужна зарубежная карта; работает всё, включая автопубликацию.

### Переменные коробки
- **Обязательные:** `ADMIN_BOT_TOKEN`, ключ посредника (сейчас `GEMINI_API_KEY`/`OPENAI_API_KEY`
  + `*_BASE_URL` — свести к одному), `LICENSE_KEY` (новая).
- **Необязательные (заглушки):** `LEAD_BOT_TOKEN`, `TG_CHANNEL_ID`, `IG_ACCESS_TOKEN`, `YT_CLIENT_ID`,
  `YT_CLIENT_SECRET`, `VK_*`, `MUSIC_API_KEY`, `SEARCH_PROVIDER`, `SEARCH_API_KEY`, `*_API_KEYS` (пулы).
- Сейчас движок читает: ADMIN_BOT_TOKEN AUTO_PLAN BOT_DATABASE_URL BOT_USERNAME COPY_MODEL CTA_URL
  DATA_DIR ELEVENLABS_API_KEY GEMINI_* GOOGLE_* IG_* IMAGE_* LEAD_BOT_TOKEN MAX_BOT_URL MUSIC_* NICHE
  OPENAI_* PERSONA_GENDER PUBLIC_BASE_URL PUBLISH_HOURS SEARCH_* TG_CHANNEL_ID TRENDS_WITHOUT_SEARCH
  TZ_NAME VK_* YT_* — в коробке большинство должно иметь разумные значения по умолчанию.

## 6. Этапы и критерии готовности
1. **Шаблон.** Данные Максима вынесены в профиль; один ключ посредника; владелец по ключу лицензии;
   `/doctor`. *Готово, когда:* чистая установка с 3 переменными стартует, `/doctor` всё зелёное,
   боевые движки Максима работают как раньше.
2. **Мастер настройки.** Вопросы → профиль → первая разведка; `/profile` для правки.
   *Готово, когда:* на тестовой нише (например, психолог) за 10 минут после установки приходят темы
   и первый пост по правилам площадки.
3. **Развёртывание и инструкция.** Шаблон Railway, конфигурация Amvera, памятка покупателю на 1 страницу.
   *Готово, когда:* человек без опыта разворачивает по памятке за 15 минут.
4. **Лицензия и лимиты.** Проверка ключа, месячный лимит расходов, расход в `/balance`.

## 8. Правила, которые действуют для движка
- Только правда: никаких выдуманных кейсов, клиентов, цифр, цен; цифры — только из найденных фактов.
- Цены и стоимость проектов в контенте не называть.
- Читателя не уводить на другую площадку: призыв — личка/комментарии/директ той же соцсети
  (Telegram → бот заявок допустим).
- Instagram (РФ, с 01.09.2025 запрет рекламы): только польза, без призывов заказать.
- Telegram: текст поста с картинкой/альбомом/видео — подпись, максимум 1024 знака вместе с призывом.
- Фото «реф» — только для сходства лица; исходные фото в контент не попадают никогда.
- Публикация — только после одобрения владельца.
- Перед каждым коммитом — все тесты зелёные (`python3 -m unittest discover -s tests`).

## 9. Известные грабли
- Посредник иногда отвечает потоком (SSE) без запроса — `llm._merge_sse` склеивает.
- Ключи посредника имеют лимит токенов на ключ (HTTP 402 «token allowance exhausted») — нужны пулы.
- gpt-image принимает максимум 4 фото-образца.
- Railway иногда падает на сборке без логов до начала — помогает повторная сборка (пустой коммит).
- VK ID не даёт новым приложениям права на стену и видео → VK в полуавтомате.
- Google OAuth в статусе «не проверено» — до 100 пользователей, для владельца достаточно.
- Meta: приложение опубликовано; аккаунты подключаются ролью «Тестировщик Instagram».
