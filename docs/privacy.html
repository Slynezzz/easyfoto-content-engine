Политика конфиденциальности

Приложение используется только владельцем для публикации собственных роликов в его аккаунты.

Какие данные используются. Ключи доступа к аккаунтам владельца (YouTube, Instagram, VK), которые он выдал при входе; название канала; статистика опубликованных роликов (просмотры, лайки, комментарии).

Как используются. Только для загрузки роликов, которые владелец одобрил, и для подсчёта их статистики. Данные YouTube не передаются третьим лицам, не продаются и не используются для рекламы.

Хранение. Ключи хранятся в закрытой базе приложения на сервере владельца. Доступ можно отозвать в любой момент: myaccount.google.com → Безопасность → Сторонние приложения; после отзыва ключи перестают действовать.

Приложение использует YouTube API Services; действуют Условия использования YouTube и Политика конфиденциальности Google.
